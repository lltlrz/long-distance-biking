# 骑迹计划｜长途骑行补给感知与分日路线规划

`骑迹计划` 是一个面向长途骑行者的产品经理案例项目。项目聚焦 2 天及以上骑行场景，在传统地图路线规划基础上补充沿途补给识别、分日行程规划和安全风险提醒，帮助用户从“知道怎么走”升级为“知道每天骑到哪里、哪里能补给、哪段路要谨慎”。

本仓库包含完整的产品方案、PRD、用户流程、信息架构、原型说明、作品集包装，以及一个可直接预览的静态交互 Demo。

## 项目亮点

- 面向长途骑行场景拆解真实用户问题：补给不确定、分日规划困难、安全风险前置不足。
- 输出从产品方案到 PRD 的完整产品文档链路，覆盖用户、场景、功能、页面、数据、埋点和验收标准。
- 提供用户流程、信息架构、低保真原型和高保真原型说明，体现从问题定义到方案落地的设计过程。
- 使用 HTML/CSS/JavaScript 制作可交互 Demo，便于在作品集或面试中演示核心体验。
