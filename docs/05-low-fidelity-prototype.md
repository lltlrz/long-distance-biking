# 骑迹计划低保真原型

## 1. 低保真原型目标

低保真原型用于验证页面结构、信息优先级和核心交互路径，不追求视觉精细度。该版本为 Figma 高保真原型和可交互 Demo 提供布局依据。

## 2. 原型范围

本次低保真覆盖 5 个核心页面/状态：

1. 路线规划页
2. 行程总览页
3. 每日行程详情页
4. 补给图层页
5. 行程调整页

## 3. 页面一：路线规划页

页面目标：收集生成长途骑行计划所需的最小输入。

│                                              │
│ 终点                                          │
│ ┌──────────────────────────────────────────┐ │

│ └──────────────────────────────────────────┘ │
│                                              │
│ 计划天数                                      │
│ ┌──────┐                                     │
│ │  3   │ 天                                  │
│ └──────┘                                     │
│                                              │

关键交互：

| 交互 | 反馈 |
|---|---|
| 输入起终点 | 展示候选地点 |

| 切换强度 | 更新建议日里程说明 |
| 点击生成 | 进入行程总览页 |

## 4. 页面二：行程总览页

页面目标：让用户快速判断“这份计划是否可执行”。

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ 顶部：骑迹计划                      [重置] [保存行程]                    │
├───────────────┬──────────────────────────────────────┬──────────────────┤
│ 左侧规划条件   │ 中间地图路线                          │ 右侧每日行程      │
│               │                                      │                  │
│ 起点 成都      │        ● 成都                         │ Day 1 成都→眉山   │
│ 终点 乐山      │          ╲                           │ 78km 5.0h        │
│ 天数 3         │           ╲  餐 便                    │ 补给低            │
│ 总里程 246km   │            ● 眉山                      │                  │
│               │             ╲                         │ Day 2 眉山→夹江   │
│ 强度           │              ╲====补给空窗====         │ 88km 5.7h        │
│ [轻松][标准][挑战]│             ● 夹江                    │ 补给中            │
│               │               ╲                       │                  │
│ 偏好           │                ╲ 住 餐                 │ Day 3 夹江→乐山   │
│ ☑住宿 ☑补给    │                 ● 乐山                  │ 74km 4.8h        │
│ ☑安全 ☐少爬升  │                                      │ 补给低            │
│               │                                      │                  │
│ [生成计划]     │ 图例：路线 / 补给点 / 补给空窗          │ 补给与安全提醒     │
└───────────────┴──────────────────────────────────────┴──────────────────┘
```

关键交互：

| 交互 | 反馈 |
|---|---|
| 点击每日卡片 | 高亮对应日路线并进入详情 |
| 点击补给图层按钮 | 显示/隐藏餐饮、便利店、住宿、城镇 |
| 点击补给空窗 | 展示空窗距离、风险原因和建议 |
| 点击保存 | 出现保存成功提示 |

## 8. 低保真到高保真的设计转化

| 低保真元素 | 高保真表达 |
|---|---|
| 三栏布局 | 左侧控制面板 + 中间地图画布 + 右侧行程面板 |
| 补给点符号 | 使用不同颜色和图标区分餐饮、便利店、住宿、城镇 |
| 补给空窗线段 | 红色虚线或高亮路段 |
| 风险提示 | 使用黄色/红色风险卡片，配具体建议文案 |
| 行程卡片 | 清晰展示 Day、起终点、里程、耗时、爬升、补给状态 |
| 调整终点 | 候选终点列表 + 调整影响对比 |
