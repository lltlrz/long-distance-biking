## 3. 高低保真 Frame 清单

| Frame | 关键内容 |
|---|---|
| 01 规划输入 | 起终点、天数、强度、偏好、生成 AI 骑行方案 |
| 02 规划结果 | 三栏工作台、地图路线、每日行程卡片 |
| 03 每日详情 | AI 推荐解释、里程、爬升、补给和安全提醒 |
| 04 补给图层 | 餐饮、便利店、住宿、城镇、维修与 31km 补给空窗 |
| 05 动态调整 | 疲劳、天气、时间、进度输入 |
| 06 影响预览 | 夹江调整为丹棱、里程与风险前后对比 |
| 07 保存成功 | 轻量 Toast 状态 |
| 08 生成失败 | 保留输入并提供修改与重试 |

## 4. 核心组件

- 主按钮、次按钮、文字按钮和禁用状态。
- 轻松/标准/挑战分段控件。
- 安全、提醒、高风险三类状态标签。
- 每日行程卡、AI 推荐理由卡、补给提醒卡和安全风险卡。
- 餐饮、便利店、住宿、城镇、维修五类补给标记。
- 动态调整抽屉、表单字段和调整影响对比组件。

## 5. 视觉规范

- 深绿/青绿：品牌、主操作、路线和选中状态。
- 橙色：需要关注的建议和中风险。
- 红色：明确的补给空窗或高风险。
- 绿色：补给充足与安全状态。
- 地图保持最高视觉权重；AI 信息使用解释卡和影响卡，不使用聊天气泡。

## 6. 原型交互

```text
规划输入 → 生成方案 → 规划结果 → 打开动态调整 → 生成建议
        → 影响预览 → 确认重新规划 → 更新结果 → 保存成功
```

取消动态调整时返回未变化的规划结果；确认重新规划后，Day 2 终点、里程、补给空窗和风险同步更新。

## 7. 与 Demo V2 的对应关系

Figma 与 `demo-v2/` 统一使用成都至乐山 3 日、246km 示例，Day 2 为眉山至夹江 88km，存在 31km 补给空窗；疲劳调整后推荐丹棱 76km。
