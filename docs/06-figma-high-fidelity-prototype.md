# 骑迹计划 Figma 高保真原型

## 1. Figma 文件

文件名称：骑迹计划 - 高保真原型

Figma 链接：https://www.figma.com/design/uek2SBQw8A3WZPxa8WvLn0

## 2. 原型范围

本次高保真原型覆盖 5 个移动端主流程页面：

1. 01 路线规划页
2. 02 行程总览页
3. 03 每日详情页
4. 04 补给图层页
5. 05 行程调整页

## 3. 设计目标

高保真原型用于将 PRD、用户流程图、信息架构和低保真原型转化为可展示的视觉方案。重点不是做完整地图 App，而是展示长途骑行规划的核心产品能力：

- 输入起终点、计划天数和骑行强度。
- 生成分日行程。
- 在地图中展示路线、补给点和补给空窗。
- 展示每日行程卡片。
- 解释补给风险和安全风险。
- 支持替换每日终点。

## 4. 页面说明

### 4.1 路线规划页

核心信息：

- 起点：成都
- 终点：乐山
- 计划天数：3 天
- 骑行强度：轻松、标准、挑战
- 路线偏好：住宿优先、补给优先、安全优先、少爬升
- 主操作：生成骑行计划

设计意图：让新手用户在不理解复杂骑行参数的情况下，也能快速生成一个长途骑行计划。

### 4.2 行程总览页

核心信息：

- 成都到乐山 3 日路线
- 总里程和预计骑行时间
- 地图路线
- 餐饮、便利店、住宿、城镇图层
- 红色补给空窗提示
- Day 1-3 每日行程卡片

设计意图：让用户同时从空间地图和每日列表两个维度判断计划是否可执行。

### 4.3 每日详情页

核心信息：

- Day 2 眉山到夹江
- 推荐终点理由
- 当日补给节点
- 补给空窗
- 国道路段和弱网络提醒
- 主操作：替换终点

设计意图：解释系统推荐逻辑，增强用户对自动分日规划的信任。

### 4.4 补给图层页

核心信息：

- 补给类型筛选
- 地图 POI 分布
- 补给密度条
- 补给空窗提示

设计意图：把普通 POI 搜索转化为沿路线的补给能力判断。

### 4.5 行程调整页

核心信息：

- 当前 Day 2 终点
- 候选终点：丹棱、夹江、乐山
- 每个候选终点的里程、补给和住宿状态
- 调整影响：Day 2/Day 3 里程变化、补给空窗减少
- 主操作：确认调整

设计意图：保留用户主动控制权，避免系统推荐显得不可修改。

## 5. 原型交互

当前已设置 3 个基础跳转：

| 起点 | 操作 | 终点 |
|---|---|---|
| 路线规划页 | 点击“生成骑行计划” | 行程总览页 |
| 每日详情页 | 点击“替换终点” | 行程调整页 |
| 行程调整页 | 点击“确认调整” | 行程总览页 |

## 6. 视觉规范

| 类型 | 规范 |
|---|---|
| 主色 | 深绿色/青绿色，用于品牌、按钮和选中状态 |
| 风险色 | 红色用于补给空窗和高风险提醒 |
| 提醒色 | 黄色用于中风险和建议提醒 |
| 安全/补给正常 | 绿色用于补给充足、状态正常 |
| 信息结构 | 卡片化承载行程和风险，地图区域居中展示空间关系 |
| 字体 | 使用 Figma 可用字体，保持中文可读性和层级清晰 |

## 7. 和可交互 Demo 的关系

Figma 高保真原型用于作品集展示视觉设计和页面结构；代码 Demo 用于展示真实交互和状态变化。

两者分工如下：

| 交付物 | 价值 |
|---|---|
| Figma 高保真原型 | 展示页面设计、信息层级、视觉规范、用户流程 |
| 可交互 Demo | 展示生成计划、切换强度、筛选图层、埋点日志等动态能力 |
